# Paperbrew Mac App Implementation Plan (PR 4 of 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A menu-bar Mac app that the user downloads, opens and connects with one click from Settings, and that prints queued issues on their printer with no Terminal.

**Architecture:**
- An Electron app in a new workspace `apps/mac`.
- The printing logic lives in pure, unit-tested modules: `lp` arguments, `lpstat` parsing, deep-link parsing, status text, and a `runOnce` loop step with injected API and print functions.
- `main.ts` is a thin shell: tray menu, `paperbrew://` protocol handler, `safeStorage` token, login item, notifications and a 60-second timer.
- The `.dmg` is built with electron-builder.

**Tech Stack:** Electron (latest stable), electron-builder, TypeScript, vitest.

**Spec:** `docs/superpowers/specs/2026-11-22-autonomous-brew-design.md` (section 3, "The Mac app").

**Depends on:** PR 3 merged (agent HTTP contract below).

## Global Constraints
- **Users never use Terminal.** The app runs `lp`/`lpstat` itself via `execFile` (never a shell string).
- **API contract** (base = the `api` param from the pair link + `/api`):
  - `POST /agent/pair { code, name }` → 201 `{ token, deviceId }` | 410
  - `POST /agent/jobs/claim` → 200 `{ id, layout: 'flat' | 'booklet' }` | 204
  - `GET /agent/issues/:id/pdf` → 200 PDF | 204 (nothing to print; already marked printed) | 503 with `Retry-After`
  - `POST /agent/issues/:id/result { ok, error? }` → 204
  - Any 401 → the device was removed.
- **`lp` arguments:**
  - booklet → `-o sides=two-sided-short-edge -o media=A4`
  - flat → `-o media=A4`
  - `-d <printer>` only when the user picked one
- **Polling and identity:** poll every 60 s. Device name = `os.hostname()` without `.local`.
- **Menu-bar only:** no Dock icon (`LSUIElement`); "Start at login" on by default.
- **Deep links:** accept only `paperbrew://pair?...` whose `api` is `https://…` or `http://localhost:<port>`.
- **Unsigned this round.** The build config takes a signing identity from env (`CSC_NAME`) and runs unsigned without it (`CSC_IDENTITY_AUTO_DISCOVERY=false`).
- **Universal `.dmg`** (arm64 + x64).
- **Vercel needs no Electron setting:** Electron 45 has no install script and only downloads its binary on first run, so the `apps/api` and `apps/web` builds are unaffected (`ELECTRON_SKIP_BINARY_DOWNLOAD` is not needed).

## Review Focus
1. **The Mac sleeps or the network drops mid-download.** The issue stays claimed. The next tick retries the download for the same issue before claiming a new one, and no result is reported until it prints (Task 2 test `retries the pending issue first`).
2. **The device was removed in Settings.** On 401 the app clears its token, shows "Not connected", and stops polling until paired again (Task 2 test).
3. **The chosen printer was unplugged or renamed.** `lp` fails with "The printer or class does not exist". The app reports failure with that text and falls back to the default printer next time (Task 2 test `missing printer`).
4. **The pair link opens before the app is running.** macOS launches it with the URL. The handler must be registered before `ready` (`will-finish-launching` + `open-url`), so the link isn't lost (manual check in Task 4).
5. **A second app instance from a double launch.** Only one polls (`requestSingleInstanceLock`), so no double prints (manual check in Task 4).

### Task 2: API client and the poll step

**Files:**
- Create: `apps/mac/src/api.ts`, `apps/mac/src/loop.ts`
- Test: `apps/mac/test/loop.test.ts`

**Interfaces:**
- Consumes: `lpArgs`.
- Produces:
  - `class UnauthorizedError extends Error`
  - `class OfflineError extends Error` (network failure or 5xx)
  - `createApi(base: string, token: string | null, fetchImpl = fetch)`, returning:
    - `pair(code: string, name: string): Promise<{ token: string; deviceId: string }>` (410 → `Error('code expired or used')`)
    - `claim(): Promise<{ id: string; layout: 'flat' | 'booklet' } | null>`
    - `downloadPdf(id: string): Promise<Uint8Array | null>` (204 → null; 503 → `OfflineError`)
    - `report(id: string, r: { ok: boolean; error?: string }): Promise<void>`
  - `type LoopDeps = { api: ReturnType<typeof createApi>; print(file: string, layout, printer: string | null): Promise<void>; writeTemp(bytes: Uint8Array): Promise<string>; removeTemp(file: string): Promise<void>; printer: string | null }`
  - `type Pending = { id: string; layout: 'flat' | 'booklet' } | null`
  - `runOnce(deps: LoopDeps, pending: Pending): Promise<{ outcome: 'idle' | 'printed' | 'failed' | 'unauthorized' | 'offline'; pending: Pending; error?: string; printerMissing?: boolean }>`

`runOnce` does this:
1. `job = pending ?? await api.claim()`. No job → `idle`.
2. Download. `OfflineError` → `offline`, with `pending = job` so it's kept. null → `printed` (nothing to print, no report).
3. Write the temp file, then `print`.
   - Success → `report ok` → `printed`.
   - `print` rejects → `report { ok: false, error: stderr }` → `failed`. Set `printerMissing` when the stderr matches `/does not exist/i`.
4. Always remove the temp file.

Any `UnauthorizedError` → `unauthorized` with `pending: null`.

- [ ] **Step 1: Failing tests** (fake api/print):
  - claim null → `idle`
  - full success → print called with booklet args, `report({ ok: true })`, `printed`
  - `retries the pending issue first`: pending set → `claim` not called
  - download `OfflineError` → `offline`, `pending` returned
  - download null → `printed`, no print, no report
  - `missing printer`: print rejects with `lp: The printer or class does not exist.` → report `{ ok: false, error: … }`, `printerMissing: true`
  - claim `UnauthorizedError` → `unauthorized`
  - the temp file is removed on failure too
  - `createApi`: 204 claim → null; 401 → `UnauthorizedError`; fetch throws → `OfflineError`; it sends `authorization: Bearer <token>`.

### Task 3: The Electron shell

**Files:**
- Create: `apps/mac/src/store.ts`, `apps/mac/src/main.ts`, `apps/mac/src/paste.html` (+ a minimal `preload.ts` exposing `submitCode(code)` over IPC)

**Interfaces:**
- Consumes: Tasks 1–2.
- Produces:
  - `store.ts`:
    - `loadToken(): string | null`
    - `saveToken(t: string): void` (encrypted with `safeStorage.encryptString` to `userData/token.bin`)
    - `clearToken(): void`
    - `loadSettings(): { api: string | null; printer: string | null; lastPrintedAt: string | null }`
    - `saveSettings(patch): void` (`userData/settings.json`)

Shell behavior:
- `app.requestSingleInstanceLock()`; quit if not acquired.
- Register `open-url` inside `will-finish-launching`. `app.setAsDefaultProtocolClient('paperbrew')`.
- On a valid pair link: call `pair`, then `saveToken`, `saveSettings({ api })`, and notify "Connected to Paperbrew".
- Tray with `IconTemplate.png` and a menu rebuilt on every state change:
  - the status line (disabled item);
  - `Last printed <date>` when known;
  - **Printer ▸** a radio list from `parsePrinters(execFile('lpstat', ['-p', '-d']))`, plus "Default printer";
  - **Start at login** checkbox (`app.setLoginItemSettings({ openAtLogin })`, defaulting to on at first run);
  - Open Paperbrew (`shell.openExternal(api + '/app/settings')`);
  - Paste code… (opens `paste.html`);
  - Disconnect (`clearToken`);
  - Quit.
- A timer every 60 s, and once at startup, while connected:
  - `printed` → notify "Your issue is printing" and save `lastPrintedAt`;
  - `failed` → notify `Couldn't print your issue: <error>`, and when `printerMissing`, reset `printer` to null;
  - `unauthorized` → `clearToken`, state `not_connected`.
- `print` = `execFile('lp', lpArgs(...))`, rejecting with stderr. `writeTemp` uses `os.tmpdir()`.
